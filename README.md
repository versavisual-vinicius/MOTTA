# Reconstrução local — Barbearia Motta

Protótipo responsivo da página inicial e do fluxo de novo agendamento do CashBarber, reconstruído a partir de evidência de runtime e dos chunks funcionais enviados ao navegador.

## Executar

```bash
pnpm install
pnpm dev
```

O protótipo usa somente dados locais e não chama a API do CashBarber. O botão “Agendar” termina em uma confirmação simulada.

Documentação: [fluxo](docs/FLOW.md) e [mapa de APIs](docs/API_MAP.md).
